# 0.88.3（104）测试操作

选择普通带小组件 IPA 或 TrollStore 专用 IPA，按对应方式覆盖安装并保留已有钥匙。

1. 打开「车控 → 能耗数据 → 自动行程记录」，开启记录。刷新车况后，页面显示收到的有效行程公里和最后上报时间。
2. 在途中停车并取得较新车况。同一车端编号应更新原记录。等车端编号切换后，列表应另增一条。跳号时显示可能漏段。关闭记录后已有记录保留。
3. 车端编号和距离取自现有车况，数据保存在本机并按账号及车辆区分。停车时可能仍是同一段。App 未获得车况期间可能漏记。第一版记录里程，暂不计算逐段电耗。
4. 对于充电、门窗或舱盖未关和已确认的哨兵变化，检查首页状态岛、锁屏及灵动岛显示。需要系统重要变化提示时，在设置的「操作反馈」开启。iOS 调度与车况上报会影响刷新。
5. 有需配对的设备可检查系统弹窗和键盘出现时，页面顶部配对码是否可读。已有可用钥匙请继续使用。
6. 在新款 MG4 上检查六种车漆、悬浮顶、侧窗升降和深浅色灯光表现。

本版 645 项单元与 22 项模拟器界面测试通过。设备安装、小组件运行时共享、系统蓝牙配对及实车效果待进一步验收。
