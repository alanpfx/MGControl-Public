# 0.87（98）使用与验收

正式云端 613 项单元 + 17 项原生 UI 零失败；三种最终 Release IPA 的版本、摘要、权限、资源及兼容性检查通过。以上不是设备和实车全部通过。

0.87（98）设备与实车验证（云端/包检查另记）
1 覆盖安装保留账号/钥匙；普通证书与TrollStore分别记录启动、共享容器与Widget回执，勿通用卸载或重领钥匙。
2 首页长按任一卡片进入编辑，不触发原功能；始终没有手动单双列/大字号选择。正常宽度双列，旧单列偏好不再恢复。拖动吸附、上下移/边界、默认草稿、保存取消及重进检查反馈。
3 普通点击实际白卡中心应进入对应页面，空调独立按钮有确认/错误提示，复制按钮就近显示已复制；实际车控执行仅在车主主动授权的场景验证。
4 iCloud在同Apple账户/兼容签名的两机开启钥匙串后，A显式发布，B检查并确认采用，不短信登录；分别记录到达/采用/读取与长期14101，未测不能说同步成功。不改蓝牙身份/PIN。
5 本地账本输入真实账单，区分金额空白与0、首笔基准、30km累计完整分母、跨月和SOC估算；编辑重算/删除取消确认、重启保存、CSV分享/文件保存及官方入口分别测。账本不云同步。
6 既有首页四控、充电/锁枪、哨兵、保电、备车、蓝牙/无感、Siri/实时活动、照片权限等按原分层矩阵逐项测试，受理不等于车辆成功；未知不重发。
7 iOS15与较新iOS/大字号/旋转/VoiceOver、3D长时与后台恢复分别记录。本轮没有这些设备/实车结论前保持未验证。


iCloud操作顺序（真实设备待验）
主设备有效登录后：设置→iCloud共享登录→启用→同步当前登录→确认。另一设备用同一Apple账户开启iCloud密码与钥匙串，且两端相同兼容签名→启用共享登录→检查→核对车辆→确认使用。其他设备不再短信登录。发布显示已提交不等于另一设备已收到，需按A→B→A→B读取验证。云端未到达时保留本机登录，不清除已有钥匙。默认关闭；账本不参与同步。

本地账本说明
首页能耗卡→添加充电记录。首笔里程只作基准，充电量/已知金额计入账单汇总；从后续记录形成区间，短于30km的区间合并后按完整分母加权。SOC估算需手工填可用容量；不以标称90%冒充可用容量。费用缺失不按免费；删除后下一笔重置区间基准以避免假低电耗。原官方页面从“官方数据”打开。
