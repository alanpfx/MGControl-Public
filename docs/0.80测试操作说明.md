# 0.80（79）设备测试步骤

已有钥匙请覆盖安装，保留蓝牙账号及钥匙；不清除或重新领取。

1. 悬浮导航缩小后，点击三个按钮的图标、文字和旁边空白区均能切换；各页滚动到底，最后一项能露出导航上方。默认字号每个按钮仍至少44pt高。
2. 设置→登录/更新主账号凭证先出现确认，再打开独立短信页；取消保持原凭据与钥匙。忙碌时显示原因。勿用本测试重复领取钥匙。
3. 无感设置开关即时保存；退出再进保持。信号阈值、持续时间和冷却在同一卡片内保存并提示结果。未保存规则不应随其他开关提交，保存规则不应回退其他开关。
4. 原厂无感方案点入才显示参数状态；UUID/Major/Minor仅在高级折叠内。未识别时开关禁用并说明原因；不能猜测参数，广播只帮助连接，解锁仍需认证及规则。
5. NFC与Siri语音卡片精简说明；点击预设动作入口跳转系统快捷指令。复制兼容链接有反馈；NFC标签需在系统自动化扫描。系统授权、前台等待、当前账号车辆和未知结果不重发仍保留。
6. 新建备车计划空名保存应提示填写名称；填写后保存并读回确认，预约开关/时间/星期保持。保存不立即备车。未知结果先读取核对。
7. 小组件在系统深色时手动选App浅色，App及组件均变浅，反向也测；跟随系统、着色/透明模式单独测。记录最终签名方式、运行时共享组与组件回执。
8. 两侧前窗下降无重复内框，关闭玻璃完整；尾门保持0.78原联动并能复位。新鲜成功回执后前台可见动画，失败/旧结果不演示；解锁灯效仅为展示，不向车辆发送新增灯光命令。
9. 保留0.78后台增强模式耗电、车内不误解锁、Siri与通知时序、离线钥匙及远控主凭据独立回归。实车由车主按停车安全条件逐项操作，不能因模拟器通过宣称实车全通过。
