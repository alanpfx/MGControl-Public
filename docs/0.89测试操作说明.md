# MGControl 0.89（106）测试版验收

安装与基础回归
普通证书带小组件 IPA 与 TrollStore IPA 分别覆盖安装和冷启动。按实际签名核对 App Groups、Widget 读取回执、主账号及车辆选择、已有蓝牙钥匙。记录系统及机型。最低目标 iOS 15.0。

首页 3D 与涂装
浅色、深色各转一圈，核对无圆角裁切、缩放禁用、纵向滚动及 320 宽度构图。看月光白和东来紫、前后挡和侧窗、悬浮顶及尾翼接缝、灯熄灭和点亮。保持六色可切换。
车辆外观保存模板，分别选取有效 PNG/JPEG、错误尺寸、超限图片和取消面板。核对亮面／哑面、恢复原厂漆取消和确认、图案随车门与尾门、重启、切账号和切车辆。
真实设备检查 WKWebView 图片加载、流畅度、内存及从文件提供器选择内容。

充电
充电设置页显示数据及按钮，模型留在首页。分别设 1、2、5 分钟验证连续两轮以上的读取时间。制造超时后核对继续只读查缓存，数据时间没有更新时保留缓存。锁屏和恢复分别记录。
实际结束充电后验证比上一次充电中更新的 1011 收起状态岛，检查旧 1011 或未知态不提前消失。首页背景保持中性，盖板贴合开口、插枪和线缆连续，退出时盖板复位。
手动刷新、停止充电与车控恢复按已有授权实车闭环。模拟器和包检查仅证明相应层次。

Widget
经典布局回归，浅色、深色与着色核对设计 01 和 02 的字号、图标、窄宽度按钮区与四个入口。覆盖普通确认和用户已授权的快捷模式。

蓝牙与其它入口
已有钥匙继续使用，分开记录系统自动重连、认证和车主触发动作。回归账号、车况、自动行程、充电费用、诊断复制、设置开关、页面进出和取消。按钮覆盖按单独清单记录。
