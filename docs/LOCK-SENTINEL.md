# 锁车后自动开启哨兵

入口：设置 → 锁车后自动开启哨兵，或首页“哨兵与消息”中的同名设置。默认关闭，按当前账号车辆保存。先在安全码设置保存车辆安全码，再明确开启自动功能。

流程：本App锁车明确成功 → 有限刷新新车况 → 确认操作后已上锁 → 查询哨兵 → 若为已知关闭状态，校验安全码并再次读门锁 → 提交一次开启请求。无需逐次弹窗。受理后仍显示最终结果待核实，不把未知状态当作成功。

每次锁车周期只尝试一次，失败或离线不补发；已消耗周期跨重启保留。本App成功解锁后准备新周期。本App手动操作哨兵会取消尚未提交的自动任务，并抑制本周期自动开启。外部App/实体钥匙的所有动作无法保证实时监测。

测试：保持联网、保存安全码、开启功能，先通过本App解锁一次再锁车；查看新车况核验及自动哨兵记录，实车或官方App确认状态。另测试蓝牙锁车、重复回执、手动关闭、离线锁车。网络/安全码/权限失败应停在未确认，不重发。若需要登录官方App检查，可能使本App登录失效，应事先导出诊断。

哨兵可能增加车辆耗电。系统后台时间结束时流程可能中止；不保证App被强退后继续执行。锁车确认不是下电检测；当前开启最终状态码仍需真实样本验证。
