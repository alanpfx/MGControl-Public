# MGControl 0.90（114）覆盖安装与测试

普通版使用当前签名方式覆盖安装。TrollStore 用户使用专用 IPA 覆盖安装。保留已有钥匙和设置。安装后在「设置」核对版本，再刷新一次车况，检查脱敏诊断里的主程序构建和小组件的新时间线回执。

## 蓝牙信号和快捷操作

1. 开始监测，打开「蓝牙钥匙 → 无感开关锁设置」。阈值参数上方显示 RSSI 信号尺和最近 30 秒采样曲线。
2. 调整近车或离车阈值，确认信号尺标记与曲线参考线同时移动。保存后，展开灵动岛或查看锁屏实时活动，确认标记使用新值。连续计时使用保存后的有效采样。
3. 等待连接时，快捷操作显示「临时下车／上车」。蓝牙认证完成后显示「上锁」和「解锁」。在设置页或实时活动上单击车锁操作后，核对实车锁态和结果提示。实时活动的上锁和解锁沿用已有的蓝牙快捷权限，锁屏时按系统要求认证。
4. 点「临时下车」后，核对助手仍能采样并暂停助手的自动动作。从另一个入口点「上车」，核对恢复状态。原厂无感按原厂设置运行。

锁屏实时活动的交互按钮需 iOS 17 或以上。iOS 15.5 可在设置中使用蓝牙快捷操作和查看信号。

## 原厂无感设置

保持助手监测运行。读取原厂开关后，每次只改一项并确认提交，保存后查看同一绑定的读回。iPhone 17 Pro 默认保留原厂推荐距离，需要实测时再开启距离实验。

若车机在当前认证连接中请求配置，助手会使用新版签发配置。通过脱敏诊断分别记录云端读回、车辆请求及系统蓝牙发送，再观察实车动作。没有观察到当前连接请求时，重复一次自然断开和重新连接。

## iCloud 设置与小组件快捷模式

在「设置 → App 设置同步」开启自动备份。备份包含显示模式、小组件风格、实时活动和提醒偏好。在使用同一 Apple 账户和兼容签名的设备上可尝试恢复。已有钥匙、登录凭据、安全码、车辆授权和本机阈值应继续通过本机管理。TrollStore 的 iCloud 恢复需在对应签名与系统上实测。

为当前车辆授权小组件快捷模式后，等桌面按钮更新为固定动作再点击。如果桌面还在使用普通入口，助手会请求刷新。桌面更新时间由系统决定，请以最新按钮和车辆实际结果为准。
