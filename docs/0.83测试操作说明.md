# 0.83 测试操作说明

安装包：`MGControl-V0.83-widget-ready-unsigned.ipa`（带小组件）、`MGControl-V0.83-app-only-ready-unsigned.ipa`（纯 App）、`MGControl-V0.83-widget-trollstore-appgroups.ipa`（TrollStore 专用）。三包都未签名，需自行重签或 TrollStore 安装。已有钥匙和账号保留，覆盖升级即可，**不要清除或重新领取钥匙**。

## 一、原厂无感（本次重点）

1. 正常登录主账号，进入「设置 → 原厂无感方案」。
2. 若此前没填过广播参数，做完一次蓝牙钥匙连接后，本机会自动补上「本车广播 UUID」，页面会标注来源是「云端随钥匙下发」还是「本机钥匙数据推算」。
3. 走到车旁点「在车旁验证车辆广播（12 秒）」：
   - 显示收到广播 → UUID 正确，可以打开上面的开关；
   - 收不到 → 先确认 iPhone 定位权限是「始终允许」，再确认车端处于会广播的状态。
4. 打开开关后锁车离开，再靠近，观察是否出现进区域提示与连接恢复。iOS 的区域事件有延迟，不能用它衡量"解锁快不快"。

本车已核对的一组对照：MAC `F8:6F:DE:A1:B5:1F` 推算结果为 `203AC73D-9BFE-9AF9-5255-6A041F7C5574`，与安卓 nRF Connect 扫到的值一致。

## 二、按钮响应（本次重点）

1. **首页四个快捷入口**：在未保存安全码的情况下逐个点锁车、车窗、后备箱、鸣笛，应弹出「请先在安全码设置中保存安全码」的提示，而不是没有反应。执行中有转圈或按钮变淡属正常。
2. **空调卡片**：未保存安全码时点电源键、温度加减、座椅/方向盘，同样应给出提示；保存安全码后正常走确认框。
3. **充电页**：未保存安全码时页面顶部有橙色提示与「去设置安全码」入口，按钮保持禁用是预期行为。
4. 每个按钮点一次即可，重点确认「有反馈」：弹窗、提示、转圈或状态变化，四者至少出现一个。

## 三、回归

1. 车况刷新、锁车/解锁、车窗、后备箱、鸣笛、空调、座椅加热通风、寻车。
2. 蓝牙钥匙页：手动锁车/解锁、持续连接恢复、RSSI 与无感状态。
3. 小组件：锁车/解锁快捷动作、刷新与样式切换。
4. 充电页：开始/停止、预约、充电口电子锁（都需要安全码）。

## 四、记录

把失败项记成：页面 → 按钮 → 当时状态（是否登录、是否保存安全码、是否在充电/执行中）→ 现象 → 截图。这样能直接定位是禁用逻辑、请求失败还是提示缺失。
