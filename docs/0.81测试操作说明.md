# 0.81（83）测试操作说明

已有钥匙请覆盖安装并保留，不清除、不重新领取；普通签名和 TrollStore 分别记录结果。云端与包检查不代替真机和实车验收。

1. 首页五按钮：锁车、车窗、空调、后备箱、鸣笛。点击图标、文字与旁边空白都能打开入口；所有选框和确认均可取消，取消不下发车辆命令。座椅与方向盘也检查。
2. 各页和二级设置滚动到底，最后一项能完整露在导航上方；iOS26原生玻璃导航和旧系统浮动导航分别测，包含较大字号。
3. 右上蓝牙入口未认证为灰、当前车辆认证连接后为蓝，点击进入蓝牙页；不以系统蓝牙开关冒充车辆连接。
4. 空调关闭为灰、开启为蓝；缺失/过期状态先刷新并核对，再确认对应开关。刷新失败不应猜测或下发。不同温控模式、温度和时长仍分项实测。
5. 设置六种车色后检查首页及设计01中号组件；手动浅/深色、跟随系统和系统着色/透明分别测。长按编辑组件可单独选择风格；旧系统保留设置页入口。记录共享容器和扩展读取回执。
6. 检查新车模低机位、两侧三角窗、降窗/回升、玻璃入框、尾门开合复位；保留原版尾门联动。悬浮顶打开后A/C柱、顶部车框和后视镜喷漆壳颜色一致，关闭恢复车漆。明暗外观和长时间滚动返回后检查3D是否恢复。
7. 控车成功回执出现可见动画和待车况确认示意，旧缓存不应立即回滚，新鲜真实车况最终覆盖；失败或过期回执不播放成功演示。
8. 服务器临时故障或主远控凭据失效时，已有有效离线钥匙仍可进入连接并进行实车认证；联网/离线分别测。已知绑定冲突和失效钥匙不能绕过。不要用清除钥匙排查。
9. 离车保电入口只有较新车况明确开启时出现，位于车窗提示下方。点击确认后只提交一次，较新false上报才隐藏；超时和未知结果先核对，不能连续重发。
10. 哨兵开启/关闭后核对专用状态和上报时间；开启可能延迟，未确认期间不会重发。页面前台可见时定期只读更新，网络故障保留上次状态。自动哨兵单独测试前置新车况、一次提交及较新开启确认。
11. 主账号重新登录先确认，再进入独立短信页，取消保持凭据和钥匙；分享蓝牙账号不得覆盖主账号远控。设置保存/开关应有可见反馈并能持久化。
12. 备车新增、编辑、删除及预约开关、时间、星期读回；空名应提示，未知结果先读取核对，不重复保存或立即执行。保存计划和实际预约执行分别验收。
13. 保留Siri/NFC、实时活动/通知开关与时序、后台增强定位耗电、原厂无感辅助唤醒、车内不误解锁和离线蓝牙回归；系统调度不承诺常驻或准时。

卡片自由拖拽本版未包含，能耗仍未接通。实车操作须车主确认、停车环境安全，记录请求受理、执行结果与车辆状态三个阶段；不得以HTTP200代替车辆执行成功。
