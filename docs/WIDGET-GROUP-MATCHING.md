# 小组件共享组统一匹配

本版不再要求对每份证书分别生成定向配置包。主App和小组件读取安装包内同一对程序签名：原共享组在两边均存在时优先使用；原组被重签名改写时，仅在签名团队一致且有共同组时按固定排序选择同一组。不按各自“第一个可访问容器”选择，不从其他已安装App查找权限。

从签名读取的声明不代表实际容器已获授权。仍用系统containerURL检查；无交集、团队不同等异常停止共享，显示具体选择原因。仅能读取一端权限时不推测替代组；XML权限不可读（例如仅DER）时保留兼容原配置的有限路径，不保证自动适配。

适配后的数据位于组内MGControl独立子目录，只含允许的车况摘要及小组件读取回执；同组内其他App仍受该组本身的授权规则约束，子目录不是额外安全边界。不迁移登录、PIN或蓝牙钥匙，不扫描/导入其他App数据。

签名工具仍须保留小组件，并正确签署App Groups和各自应用标识。程序无法补授未授权的组，也不能修复application-identifier错误。原来已正常的巨魔包继续保留原组、精确身份与钥匙串访问组。

验证：使用0.64普通小组件版，以原证书/描述文件签名覆盖安装，不启用移除插件或移除应用组权限。打开主App读取车况；查看脱敏诊断中的共享组标识、共享组匹配原因、主App容器、小组件同步/回执及两端签名。再回桌面观察。如果失败，提供签名后IPA及诊断，不提供私钥或密码，也不要重新领取蓝牙钥匙。原系统快照可通过移除再添加桌面组件刷新，但不要卸载主App。

实际跨进程读取父App签名及系统容器授权仍待各签名方式真机验证。单个设备成功不扩大为全部证书均可用。
