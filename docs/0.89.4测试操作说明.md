# MGControl 0.89.4（110）真机测试

覆盖安装前核对签名类型和标识。普通证书与 TrollStore 分开验证。保留已有账号、绑定设备和蓝牙钥匙，不卸载、不重新领取。

1. 进入蓝牙无感设置 → 车辆广播辅助唤醒。旧版保存的参数可读。未验证时开关不可开启。车旁验证成功后手动开启，检查系统定位权限提示和状态；改参数或换绑定后需重验。诊断中分别查看系统恢复、系统自动重连、车辆广播唤醒和定位辅助唤醒。验证广播和开关时观察现有钥匙、阈值及自动车控开关是否保留。
2. 车控弹窗检查锁车、解锁、车窗和单项确认。标准字号按钮约 46 点，适配大字号和短屏，取消退出。实车指令只在明确授权后验证回执及车上效果。
3. 新款 MG4 从左右后侧复查玻璃反光，并从正前、正后、侧面做整圈旋转。检查开合和旧车模基本显示。
4. 从相册或文件导入照片，分别给机盖、左侧和右侧选图。确认机盖旋转与预览一致，每侧四块面板能连续跨缝，贴图边缘和底漆过渡自然。旧照片涂装会保留，重新应用才会重算渐隐。
5. 普通签名和 TrollStore 分别核对覆盖安装、真实 Widget 宿主、共享容器回执和动作确认。浏览器和模拟器测试不代替以上步骤。
