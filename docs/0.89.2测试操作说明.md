# MGControl 0.89.2（108）测试与验收

普通证书和 TrollStore 分别记录机型、iOS 完整版本、签名、覆盖安装和首次安装。保留已有账号和蓝牙钥匙。iOS 15 启动与相册选择以及 iOS 27 普通证书小组件分别验证。

1. 新款 MG4 照片涂装。从相册或文件选择直幅、横幅 JPEG、PNG 或 HEIC。确认 13 个缩略图采用各部位比例、初次全部选中；独立拖动、双指捏合、滑杆和重置、取消勾选、清空与全选。切换到其他部位再返回，核对原裁剪读回。确认前只能预览，取消预览或退出不替换原涂装。应用后重启并切换车辆检查隔离。验证损坏、超限、取消和 3D 未就绪时的提示与禁用状态。
2. 涂装兼容。复验六种原厂配色、主题切换、悬浮顶、三套展车、原有整车模板 PNG/JPEG 与 2D 模式。确认关闭涂装后仍可恢复同一涂装。悬浮顶打开时检查相应漆面的显示规则。
3. 新款 MG4 车模。正前方、左右侧、低机位和斜前方分别检查前灯与四只轮毂，天幕与前挡保持同款玻璃。验证窄屏旋转、开关车门车窗与后备箱的动画、充电口盖开合、进入和退出充电构图。灯光动画为车况示意。
4. 小组件。分别放置普通证书或 TrollStore 的兼容与可选风格小组件，核对共享容器、时间线回执和桌面显示。验证入口确认、取消和返回。
5. 既有功能回归包括登录、车况、蓝牙配对和钥匙复用、自动刷新、充电记账、锁车与哨兵。实车指令仅在明确授权后验证完整闭环。
