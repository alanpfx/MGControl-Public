# MGControl 0.89.7（113）真机验证

覆盖安装和小组件

1. 沿用当前签名方式覆盖安装。保留本机登录、已保存钥匙和现有小组件。
2. 打开 113 助手，在「查看脱敏诊断」记录主程序磁盘版本、主程序运行构建与磁盘构建是否一致、小组件磁盘版本。
3. 在首页刷新车况一次。等小组件写出新的时间线回执后，对照共享写入时间、车况数据时间、回执来源、回执版本和小组件运行构建。若异常，保留原安装和诊断。

iOS 15.5 首页卡片

1. 从车辆位置、完整车况、一键备车等卡片中间起手，上下滑动页面。应能滚动，手指放开后不应打开卡片。
2. 轻点卡片应进入功能。长按应进入编辑，移动卡片后可取消恢复布局。在 iOS 27.0.1 上复测同样动作。

原厂自动解锁、离车锁车和实验距离

1. 保留已有助手钥匙。在「原厂无感方案」核对两只正式开关的读回。暂停助手监测，只修改一项并确认。
2. 重新连接车辆蓝牙，核对签发配置请求、系统发送与随后收到的车辆状态。用关／开两轮实车观察各方向。
3. iPhone 17 Pro 初次进入时距离实验关闭。确定原厂开关已完成正常对照，再开启实验手动选档并确认。保留原档记录，方便恢复推荐距离。测试车边停留、到后备箱取物、正常走远，以及再次靠近解锁。助手本地阈值不改，测试时保持其他变量一致。

系统蓝牙配对

仅在系统自然要求配对时，核对蓝牙弹窗出现后本次配对码仍可读，退出到后台后不会继续显示。已配对设备无需删除配对来强制复现。导出日志时使用脱敏诊断。
