# 安装步骤与使用方法

## 1. 安装前准备

- iPhone/iPad 系统至少 iOS/iPadOS 15.0；蓝牙钥匙和车型实测主要在 iPhone 与 2026 款 MG4 上进行。
- 具有合法使用权限的车辆与官方账号，已设置好官方车控安全验证方式。
- 配置蓝牙钥匙时在车辆旁操作，随身携带实体钥匙，并保留官方 App。
- 阅读 [免责声明](DISCLAIMER.md)。不要在驾驶中安装、调试或测试自动控制。

iOS 15 保留车况、远控、蓝牙钥匙和桌面小组件；实时活动在 iOS 16.2 及以上启用，灵动岛还需支持的机型。iOS 15 真机表现仍待验证。

## 2. 下载并签名

到 [v0.56 Release](https://github.com/alanpfx/MGControl-Public/releases/tag/v0.56) 下载：

| 文件 | 适用情况 |
| --- | --- |
| `MGControl-V0.56-widget-ready-unsigned.ipa` | 主 App 和桌面小组件；签名工具需同时正确处理 App、扩展和 App Groups |
| `MGControl-V0.56-app-only-ready-unsigned.ipa` | 不含桌面小组件的兼容安装包；签名环境不支持共享组时使用 |
| `SHA256SUMS.txt` | 安装包完整性校验值 |

两种 IPA 都未签名，不能直接点击安装。使用你自己的合法开发签名或合适的设备管理方式完成签名。项目不提供苹果证书、签名账号或付费安装服务。

使用自己的 Bundle ID / App Groups 时，主 App 和扩展的共享组必须一致，并与签名授权相匹配。签名工具若只改主 App、未签扩展或未配置共享组，小组件可能不更新或无法加载。

升级时尽量保持原安装标识、签名身份和应用数据，再覆盖安装。更换签名环境或卸载可能影响本机钥匙与设置；不要为了升级先删除已可用的 App。证书过期可能需要重新签名。

## 3. 初次配置和登录

1. 本次 Release 的完整 IPA 已内置应用登录配置。打开 App 后输入自己的 MG Live 手机号，完成图形验证和短信验证；无需导入测试文件，也无需先在官方 App 登录。若仍提示缺少配置，请确认使用本次发布的完整包。
2. 登录后读取本人拥有或车主已授权的车辆，核对车型和车辆尾号。应用内置参数不是账号会话、车主身份或钥匙；不会额外授予权限。
3. 先读取车况，注意上报时间；“最近车况”并非实时值。主动刷新可能需要等待车辆响应，网络可用不代表车辆立即更新。
4. 若官方服务明确拒绝登录会话，App 会清除当前登录并回到登录界面。本地配置和钥匙按设计保留，但仍需确认有效性；不要反复发出车控操作。

不要把手机号、验证码、安全码或账号会话文件提交到 Issues。官方 App 登录或重新绑定可能影响本 App 的会话或数字钥匙设备绑定。

## 4. 车况与远程控制

- 顶部卡片显示最近车况和数据时间，可设置车辆颜色与自定义名称。
- 远程按钮第一排为锁车、解锁，下一排为车窗通风、关闭车窗、鸣笛寻车。打开入口后核对车辆和动作，再确认执行。
- 空调面板整合温度、制冷、制热和关闭。仅开启风扇、急速冷暖、座椅与方向盘功能尚未提供，不要按图标或车型配置自行推断支持情况。
- 网络远控可能要求官方安全码验证。分享钥匙不自动授予网络空调、车窗等权限；官方不给该账号的功能，本 App 也不能保证可用。
- 返回成功与实车状态仍应核对。结果未确认时不要连续重发，先到实车或官方 App 确认。

## 5. 配置蓝牙钥匙

1. 进入独立的“蓝牙钥匙”页，再打开“配置与授权管理”。先检查当前账号、车辆和本机状态。
2. 服务端显示“匹配”仅代表记录匹配，不证明本机已保存有效钥匙。以本地凭据状态和实际认证结果为准。
3. 尚未配置时，理解可能影响其他设备绑定后，再显式确认配置一次。已有有效凭据时直接连接，不要反复领取。
4. 在车辆旁进入“自动识别、配对与初始化”。自动识别要求完整车架号唯一匹配；无法识别时使用单独的手动扫描页。
5. App 显示配对码后，如 iPhone 系统弹出蓝牙配对请求，将页面上的码输入系统弹窗。显示配对码仅表示已解析到车辆广播，并不证明蓝牙已连接或钥匙认证成功。
6. 等待连接、配对、钥匙认证和初始化。先手动执行一次开关锁，确认实车成功。
7. 点击“将本次已认证设备用于自动连接”，核对“已保存”的反馈。返回上一页后启动持续连接。

官方 App 不能直接把自身私有存储中的钥匙交给 MGControl。仅在官方 App 配对过，不代表 MGControl 已配置。迁移数字钥匙可能让原设备钥匙失效，请以官方提示为准。

“清除本 App 本地凭据”只清本地资料，不撤销官方钥匙。已有抓包恢复入口仅用于维护者排障和用户自有资料恢复，不是普通用户必走的安装流程；不要公开上传原包。

## 6. 离线与无感开关锁

已准备好有效本机钥匙和连接资料后，蓝牙入口不依赖先读取网络车况；仍须手机蓝牙、系统权限和车辆认证正常。首次配置、资料准备或车辆要求新签名校时时仍可能需要网络，不能承诺所有场景完全离线。

在“无感开关锁设置”中分别启用靠近解锁和离开锁车，并调整：

- 靠近/离开信号阈值：数值是 dBm，不是米数；例如 −55 比 −85 信号更强。
- 连续达到阈值的时间：靠近 1–15 秒、离开 1–30 秒。等待时间不包括连接、认证和车辆执行用时。
- 动作冷却：10–120 秒。冷却限制再次开关锁，不应停止等待连接。

先以停车场景反复测试，保留实体钥匙。无感锁车需先有本次监测中的靠近过程，信号丢失不直接当成离车锁车依据。结果不明会暂停，需要核对车辆后再恢复。

iOS 可能限制后台信号采样，强制退出、系统终止或重启后请重新打开 App。实时活动不等于永久保活；快速离开、蓝牙断线和系统暂停均可能来不及触发锁车。请实际确认车辆已锁。

## 7. 小组件、实时活动与外观

使用带小组件的安装包：长按桌面空白处 → 添加小组件 → 搜索 MG 车控助手。主 App 先成功同步一次车况，再检查组件。按钮打开 App 的对应确认入口。

组件显示最近同步车况、更新时间、车辆地址和快捷入口；定位无权限或数据缺失时会显示缺失提示。系统深浅色变化会改变组件外观。主 App 也可在设置里选择跟随系统、浅色或深色。

开启监测实时活动后，锁屏和支持灵动岛的设备可显示连接状态、最近车况和操作反馈。展示内容可能过期，需关注更新时间；提醒是否出现、是否响铃由系统设置和调度决定。并非所有 iPhone 都有灵动岛。

## 8. 自动刷新与问题反馈

自动刷新间隔可从 10 分钟到 6 小时选择。前台和系统允许的后台任务可刷新，后台不是严格定时器；不要以此推断车辆状态一直实时更新。

遇到问题请记录版本、系统、前后台状态、动作顺序和实际车辆结果，再导出对应脱敏诊断。连接问题用连接诊断，无感/自动重连问题用自动蓝牙诊断。位置截图、账号信息和原始抓包请勿公开提交。
