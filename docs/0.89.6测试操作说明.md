# MGControl 0.89.6（112）真机验证

覆盖安装

1. 沿用当前安装方式和原签名身份。普通版包含小组件，需要原签名方式；TrollStore 用户使用 TrollStore 专用包。保留现有 App 数据。
2. 安装后在诊断里确认实际运行版本为 0.89.6（112）。
3. 如果当前仍为原厂 App 的钥匙绑定，只有在准备开始助手实车测试时才手动切回助手钥匙。重新领取会影响另一端钥匙；覆盖安装本身不会更换云端绑定。

原厂自动解锁和离车锁车

1. 在助手里用已保存的有效本机钥匙连车，确认诊断显示本机绑定匹配及车辆认证就绪。若绑定不一致，先停止测试。
2. 暂停助手监测，进入「无感开关锁设置」里的「原厂无感方案」。检查当前钥匙并读取开关。页面提示「下次蓝牙连接时生效」。
3. 只选择一个方向，确认提交一次。导出诊断，查看提交前唯一绑定匹配、同一记录和登记读回、新版签发配置保存三个结果。若提交结果不明，先读回状态。
4. 断开后重新用助手连接车辆。核对是否观察到车辆请求新版配置、配置已交系统发送及后续车辆状态。Ready 或发送状态本身无法证明车辆应用了开关。
5. 对离车锁车，关和开分别从车辆已解锁、车门全关开始。同路线离车，记录是否自动锁车及动作时间。对近车解锁，关和开分别从车辆已锁开始，同路线靠近。两轮使用同一手机并排除实体钥匙、手表和其他手机的干扰。辅助车控保持暂停。保持距离档和助手信号阈值不变。
6. 若有成功通知或新车况，请记下时间和结果。车况数据时间应晚于该轮动作。只导出脱敏诊断。

TrollStore 自动车况刷新

进入「设置」→「自动刷新车况」，选择非 30 分钟间隔，例如 2 小时，点「保存设置」。退出再进入核对值，重启 App 再核对一次。后台安排仍由 iOS 调度。
