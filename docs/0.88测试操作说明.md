0.88（101）安装后验证

使用对应普通小组件/纯App/巨魔安装包覆盖安装，已有登录/钥匙保留，不以卸载作为通用排障。
1. 首页长按卡片，确认轻微抖动、整卡可拖且不误执行卡片动作。检查拖动吸附、保存重进读回、取消保持原布局、恢复须保存后生效。系统减弱动态打开后不抖动。VoiceOver可用移动动作。
2. 车控确认弹窗浅/深模式，iOS26原生玻璃与旧系统磨砂，字号/取消可点。实际动作仅由车主授权执行一次，核对回执与新车况，未知不重发。
3. 新旧MG4侧窗及固定三角窗加深，前后挡与原版相同；降窗回升不穿模，正常反光保留。解锁灯组柔光，无地面投光，锁车淡出。检查iOS长时间运行和切页后台暂停。
4. 设置→关于→充电电气数据·只读诊断。车辆正在稳定充电时按读取，间隔30–60秒再手动读取；检查字段、数据时间、与官方同期数值。电池侧功率和桩端功率可能有差异。复制脱敏结果应就近显示已复制。该页不自动requestChargeData，不操作枪锁/充电开关、不更新首页状态；HTTP成功但旧缓存不等于实时刷新通过。
5. 设置切浅色/深色/系统模式，检查锁屏Activity背景/主次文字一起变，灵动岛保持系统黑底可读。更新时机由iOS决定；分别验证普通证书和TrollStore。
6. 保留原有登录/共享会话/iCloud、充电账本、Widget、备车/哨兵/蓝牙离线与后台行为回归；本版保留原已实装清漆/轻珠光，没有纳入独立棚拍HDR试验。
