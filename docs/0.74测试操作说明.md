# 0.74 测试操作说明

覆盖安装相同签名类型的包，保留数据。不需要清蓝牙或重新领取。

1. **界面**：点击底部每块标签的左右空白、文字和图标，均应切换；各页面滚到底，最后一行可见。设置→车辆外观中点击演示打开/演示关闭/恢复车况，三个操作都不控制车辆。
2. **预约**：一键备车→新增备车计划或编辑→预约出行→开启预约，选择北京时间及重复星期。检查提示的下次出行时间。必须超过60分钟；同周期过近会顺延下一周期。保存后重新读取核对；到点实车响应另行记录。可取消预约而保留计划，也可删除测试计划。
3. **结果通知**：设置→操作反馈与语音→车控结果通知，允许系统权限。网络/BLE操作后核对通知文字与实际结果；未确认不能显示为已成功。此功能不是服务器推送，App停止后不保证获得后续结果。
4. **询问哨兵**：设置→锁车后自动开启哨兵→开启方式→开启前询问→允许询问通知。第一次新锁车后选本次不开启；下一次解锁再锁车形成新周期后确认开启。确认前后都会核验车况，3分钟后失效。离线、账号变化、解锁或取消不会补发旧任务。
5. **Siri**：先在蓝牙钥匙→无感开关锁设置中开启本车的快捷指令授权。快捷指令App新建一条，添加MGControl蓝牙锁车动作，命名“我的MG锁车”；说“嘿Siri，运行我的MG锁车”。解锁单独建另一条，不能在同一快捷指令中连续放开锁和锁车。系统可能要求解锁/认证。iOS15用打开URL的已有回退入口，仍需确认。此版不接受‘明早8点’等任意语音预约时间。
6. **系统消息**：车辆功能中心→系统消息→远程车控执行记录，读取最近10条，与官方列表同时间正文核对。不修改已读；结束、成功和当前车辆状态三者分开。

MP已有这次官方重新登录后锁车成功的用户反馈；其他远控/长期共存仍需分别验证。不要因通知、受理编号或历史消息就认定当前车辆已锁，实际状态以车辆为准。
