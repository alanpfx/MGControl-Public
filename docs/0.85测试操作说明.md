# MGControl 0.85（87）测试说明

MGControl 0.85（87）测试版：设备与实车验收

覆盖安装并保留本机数据。不要卸载、清除钥匙或重新领取钥匙。普通签名、TrollStore、小组件宿主与不同系统分别记结果。

一、启用本次登录路径
1. 设置→登录/更新主账号远控凭据，完成一次主账号短信登录。
2. 脱敏诊断应出现“MP交换车控凭据已安全保存（安卓版路径测试）”。仅覆盖安装而没有重登，仍使用旧保存会话，不代表测到了新路径。
3. 读取车辆、刷新车况，核对车辆与上报时间。保留安全码；蓝牙账号和钥匙应保持原状。
4. 交换失败时应有反馈，本机旧凭据保留。服务器可能因该次登录撤销旧会话，保留本地副本不等于仍有效；不要连续反复登录。

二、凭据有效性与双机对照（先只读）
1. A手机登录并成功读取车况后，B手机同账号登录，再回A手动读取车况；记录各自版本、时间、业务码。
2. 测试官方App重新登录后，A、B分别只读车况是否仍成功。区分查看缓存与实际网络返回。
3. 14101等明确拒绝照实记录，不说明双机共存已成功，也不要清除蓝牙钥匙。
4. 本版没有新增“跨手机导出/导入凭据”入口；本项验证的是两台分别登录的交换token是否共存，不是复用同一份token的实验。

三、远程控制逐项闭环
车主确认车辆静止和环境允许后，分别测试锁车/解锁、车窗全开/通风/关闭、后备箱、鸣笛、空调开关/温度/时长、已有座椅/方向盘、备车、哨兵与离车保电。每次只提交一次；记录请求受理、执行结果、较新车况和实车状态，不能用HTTP200替代车辆执行。超时/结果未知先核实，不连续点击重发。
四个车控快捷入口及确认/取消、缺PIN提示、小组件四入口与蓝牙页按钮均应可点击有反馈。取消不能执行车辆动作。

四、蓝牙隔离
1. 已有钥匙直接连接认证，不重新配置；联网、断网分别验证原有蓝牙锁/解锁。
2. 单独使用分享账号配置蓝牙的设备，主账号重登后蓝牙账号不应改变。
3. 原厂辅助、增强连接、靠近/离开保护沿用原逻辑；车内静止打开App不应因刚连接而自动解锁。前后台与耗电另测。

五、充电卡片与模型
1. 实际正在充电时进入首页，等待读取状态；出现充电卡片与银灰充电桩、电缆、向车端流动绿光。
2. 电量、剩余时间和数据时间对照官方，注明缓存非实时。电压、电流、功率当前可显示“—”，不能显示低压电池电压或虚假估算。
3. 较新停止充电状态后卡片延迟约3秒收起；较旧响应不得覆盖较新状态。无网保留上次数据，过期时绿光停止。
4. 页面切后台/切标签/系统减少动态效果设置应停止或减少装饰动画；小屏和横竖屏检查充电桩、电缆不裁切。
5. 点击充电卡片可进充电管理；既有四个快捷按钮布局不变。

六、通用回归
手动/前台自动刷新时间推进、不同p12重签后的真实共享容器、小组件风格/车色/外观、Siri/NFC、实时活动通知、备车保存与预约、哨兵延迟状态、3D车窗尾门/悬浮顶、导航触摸及底部留白。至少分别记录iOS15与本机系统支持层；没有设备的项目标未测。

当前没有安装、Widget宿主、实车与双机长期有效性结论。云端与包级结果见BUILD-STATUS.json，不代表本清单全部通过。
