# 公开源码范围

自 2026-11-06 起，公开源码仓库仅提供发布文档、安装/测试说明、校验记录与经过审查的构建支持。

应用 UI 实现、设计原稿与矢量文件、界面预览工程、模型及其制作工程/材质/贴图/动画原稿不公开。完整应用、车控/BLE 协议、账号和数字钥匙资料仅保存在私有仓库。UI 设计著作权归江牧所有，模型及相关原创源码著作权归作者所有，第三方素材权利与许可不变。

作者最新决定是仅对源码保密：公开编译安装包保持现有 UI、3D 模型与功能，不删减资源。运行时资源可以从 IPA 提取，不作无法逆向或无法提取的承诺。安装包与获准提供内容继续遵守 [非商业协议](../LICENSE) 和 [版权声明](../COPYRIGHT.md)。

历史旧界面源码需要单独清理 main 和标签；当前分支移除不代表 GitHub 缓存、PR 引用、分叉或他人副本已经消失。历史清理不追溯取消已授予的许可。不要公开账号资料、安全码、车架号、抓包、私有诊断或完整源码归档。
