# 本次源码范围

这是从 0.52（36）整理的独立部分源码快照，不继承私有开发分支的提交历史。GitHub Release 的 `v0.52` 标签指向此快照，而不是完整内部工程。

## 包含

- SwiftUI 车辆卡片、快捷按钮、空调面板的展示组件。
- 面向展示的车况模型、车辆颜色和车名偏好。
- 桌面小组件、实时活动与灵动岛的视图代码。
- 本机共享缓存的通用读写代码，不含真实车况数据。
- 图标和车辆展示资源；相关品牌、素材的权益仍归各自权利人。
- 使用模拟数据的独立界面预览入口与工程配置。
- 本项目说明、安装使用方法、免责声明和更新日志。

## 不包含

- 账号登录、验证码和令牌交换的实现，服务域名/路径/参数表、请求签名、安全码处理。
- 远程车况和车控 API、命令编码、结果解析及相关测试向量。
- 蓝牙广播配对码解析、数据帧、挑战应答、密钥派生、凭据领取/校验/恢复、初始化及开关锁协议。
- 与上述接口协议连接的协调器、完整 App 的运行入口、业务模型、配置页和联调代码。
- 抓包、系统诊断、接口审计报告、历史协议说明、测试配置、账号资料、密钥、令牌、真实车辆信息。
- 完整工程构建工作流、内部源码 ZIP 与带有这些内容的开发历史。

## 与内部版本的展示差异

`VehicleControlComponents.swift` 中的业务动作类型替换为 `PreviewAction`，仅保存界面文字与图标，不含车辆指令或网络能力。`SharedVehicleStore.swift` 的安装专用共享组替换为 `group.example.MGControl`。`Preview` 与 `project-preview.yml` 是此次新增的展示工程。

因此这里不能编译或还原 Release 的完整车控程序；预览按钮不会控制车辆，Widget 代码也没有网络控制实现。不要向此分支补入个人配置来“修复缺失模块”。
