# MGControl 0.89.5（111）真机测试

使用原签名方式覆盖安装，分别核对普通签名和 TrollStore。保留现有钥匙；勿卸载、清除或重新领取。

1. 在停车状态先解锁手机，确认现有车辆和钥匙，开始监测。锁屏离车至蓝牙断开，再回车旁且保持锁屏。导出诊断，按时间核对 disconnected、connected、heldAuthorization、authenticating、ready；记录前台与受保护资料标志。资料不可用应出现 waitingProtectedData，手机解锁后才重新尝试。钥匙失效、服务器冲突、车控结果不明沿用保护。第二轮分别对照普通重连与广播辅助，记录离车、回车和打开 App 的时刻。
2. 空调卡片核对 Lo / Hi 与普通温度。备车新建与编辑分别选择两档，检查保存读回后档位正确；若实车执行，回执与车机显示分别核实。
3. 新款 MG4 解锁时观察浅色与深色下的前灯射线；查看左右斜后方约 45°，拉高、降低机位，检查尾灯罩和灯带；上锁后确认前灯射线消失。包含充电造型和普通展示。
4. 充电时首页仅一张状态卡，剩余时间、功率、电流、电压和缓存时间仍可见。若有车门、车窗和哨兵提醒，在同一张卡检查。停止充电后检查提醒和状态恢复。
5. 覆盖安装后分别核对桌面小组件更新与主 App 回执。模拟器及 IPA 静态检查与实际车辆验证分开记录。
