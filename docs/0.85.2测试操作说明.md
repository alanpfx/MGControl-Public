# 0.85.2（89）测试步骤

保留数据覆盖安装，不卸载、不清除或重领已有钥匙。

1. 设置→车辆外观切换3D/2D，重启应用确认保存；2D车辆图随车色变化，充电状态卡仍显示。
2. 设置→车辆名称与车牌填写并保存，首页名称下出现车牌；关闭显示再开启内容保留，不同车辆分别保存。
3. 充电时观察绿色流光；数据过期或减少动态效果时绿光静止保留，确认结束后退出场景。数值缺失显示空值，不用12V代替充电电压。
4. 对停稳且环境安全的车辆执行一次已授权操作：观察目标动画、等待提示、执行结果及后续车况；旧缓存不得导致立即回退，执行失败应恢复，未知应提示尚未确认。解锁后备箱的打开姿态为示意，不证明实际开盖。勿因动画重复下发车辆命令。
5. A保存加密实验文件，B不短信登录，用独立解密码选择文件；测试本机/iCloud已下载文件、取消、错码和过期反馈。文件一小时实验窗口、复制解密码五分钟；A→B→A→B只读验证不等于长期共存或远控授权。
6. 普通证书/TrollStore分别检查小组件容器、快照/时间线回执与桌面显示；本版未声称能绕过签名缺失的App Groups权限。

构建/包检查与设备安装、Widget宿主、系统Files及实车结果分别记录。
