# 0.75测试操作说明

1. 同签名类型覆盖安装。设置→主账号远程控车→登录/更新主账号远控凭证，短信登录主账号，保存安全码。无需清除已有BLE钥匙。读取车辆、读取现有车况、主动刷新分开测试，核对车辆上报时间。
2. 已有钥匙先保持当前蓝牙账号，测试离线连接和手动开关锁。首次配置时，蓝牙钥匙→设置蓝牙钥匙→选择主账号或分享账号。分享账号登录仅配置BLE，远控主凭据不变。确认领取影响后才领取一次，未知结果不重复领取。
3. 官方App重新登录后，回本App用同一主凭据读取/刷新，再在安全停车条件下分别验证锁车、解锁、车窗、空调等动作。分别记录受理、查询及实车响应，不从一个动作推广全部成功。
4. 分享BLE账号设置完成后，远控应仍用主账号和安全码；更新主账号登录后，BLE账号/资料应不变，断网仍可开关锁。明确登录失效可提示重登，但钥匙保留；网络超时不清登录或重发指令。
5. 浅/深色、手动外观下查看3D背景与周围页面；旋转、阴影及尾门演示应正常。三个标签和各子页面滚到底，最后文字/按钮应能完整停在悬浮菜单上方；开启大字号再测。

iOS15/新iOS、普通签名/TrollStore、首次/覆盖安装分别记结果。云端与静态检查不能代替真机和实车。
