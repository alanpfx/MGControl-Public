# MGControl 0.89.3（109）测试与验收

分别记录普通证书与 TrollStore 的机型、iOS 完整版本、签名、覆盖安装和首次安装。保留已有账号和蓝牙钥匙。iOS 15 启动及 iOS 27 普通证书小组件单独核对。

1. 新款 MG4 模型。从正上方、水平正前方、后方和左右斜角查看前宽后窄的天幕、前挡内角、黑色横板、前后保险杠及后侧三角窗。正视检查前挡两侧与横板的接缝，从斜上方看横板与天幕衔接。通过前挡和侧窗看中控屏及仪表屏，确认屏面清楚。低位拖到限位时检查底盘遮挡。复核四轮、灯罩、各开合件和充电口盖。
2. 新款 MG4 涂装。相册和文件选图后进入白底全屏编辑器。首次默认选机盖。逐部位换图与恢复初始照片，全选／清空，验证双侧分别连接前后门和解除连接，沿门缝移动图案。核对拖动、捏合、缩放滑杆、重置与选图失败反馈。
3. 底色和保存。更换底色后验证露出未覆盖的底漆、贴图继续显示。先预览再应用。检查返回编辑、取消、未选择、生成失败及预览未就绪的反馈。应用后重启并切换车辆，核对本机数据与旧整车模板兼容。
4. 小组件。普通证书和 TrollStore 分别核对实际桌面呈现、两端运行时 App Group、读取回执和入口确认流程。
5. 既有功能回归包括登录、车况、蓝牙钥匙复用、自动刷新、充电、自动行程与哨兵。实车指令只在明确授权的安全范围验证服务受理、车况回读与车上效果。
