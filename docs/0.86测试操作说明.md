# 0.86（97）测试操作说明

1. 两台覆盖安装，保留已有钥匙。A 保留有效登录并读取车况，在设置→共享登录凭据创建、保存加密文件，单独复制解密码。
2. B 不再次短信登录。打开相同页面，填解密码并选择文件；文件提供器不便时使用文本备用入口。
3. 解密后点击“保存为本机远控凭据…”并确认。仅替换 B 的远控凭据，不复制安全码、不替换蓝牙身份或离线钥匙。
4. 回到车控页读取车况；在 B 本机设置已有车辆安全码，再由车主确认一次远控，核对服务结果和实车状态。未知结果不重复下发。
5. 两台交替读取并核对数据时间；重启 B 后检查已保存凭据恢复与蓝牙独立可用。重新短信登录仍可能使共享会话失效。

文件导入窗口一小时，解密码剪贴板保留五分钟；文件期限不等于已保存会话期限，后者由服务器决定。iCloud自动同步未包含。
