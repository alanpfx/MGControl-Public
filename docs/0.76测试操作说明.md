# 0.76（69）测试操作说明

1. 用同一签名方式覆盖安装，进入设置点“登录/更新主账号远控凭证”。主账号短信登录，保存安全码；应能重复打开登录页，车辆列表未知结构时导出脱敏诊断，不清凭据。
2. 主账号 MP 登录凭据按账号和车辆保存，全部网络车控使用主账号。蓝牙配置选择主账号或另一个分享账号；后者单独登录并保存平台映射和钥匙，不替换主账号 token/PIN。同账号已有映射直接恢复，仍需在线/车辆认证。
3. 读取现有车况、主动刷新分开测试。登录官方 App 后回本 App 再读/刷新，在安全停车时各测试一次远控锁车与所需功能；记录车辆真实结果。只有明确登录拒绝提示主凭据过期，网络超时/车辆忙不能清凭据。蓝牙断网仍可用。不要重复领取或清除有效钥匙来测试登录。
4. 蓝牙页“重新读取本机记录”应有进度和完成提示；恢复持续连接应给出运行或缺少绑定的明确原因。首次配对按照页面提示确认配对码；系统旧配对冲突要依据具体日志处理。
5. 2026车模：浅/深色、6种颜色、旋转和缩放，分别测试尾门开→关→跟随、四门/四窗状态展示。展示动画不能当作车辆已开合证据。检查实际WKWebView性能、温度和内存。
6. 首页、蓝牙、设置及其子页滚动到底，最后按钮应完整在悬浮导航上方至少24pt；大字号再次检查。点击每个导航标签整块区域均应切页。
7. iBeacon 辅助默认关闭。官方SDK方法名仅说明SDK支持，尚无本车广播参数证据。必须先确认这辆车自己的UUID/Major/Minor，在无感设置里填写后启用并保存，允许“始终定位”和后台刷新。不要填车架号、普通BLE设备UUID或网上示例。参数未知时跳过该项，基础BLE功能继续可用。
8. 先关闭iBeacon做靠近对照，再开启测试桌面/锁屏靠近。记录是否收到iBeacon事件、发起连接、认证就绪和解锁各时间。iBeacon只辅助连接，事件本身不触发锁车/解锁；退出区域不锁车。强退/系统回收不能保证恢复；没有实际事件不能判定有效。

iOS15和新系统、证书签名与TrollStore、首次/覆盖安装分开记录。本说明不是全部设备/实车已通过的证明。
