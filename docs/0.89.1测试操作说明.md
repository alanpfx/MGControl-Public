# MGControl 0.89.1（107）测试与验收

设备范围：普通证书和 TrollStore 分别记录完整 iOS 版本、机型、签名和覆盖安装结果。沿用已有账号与蓝牙钥匙。

1. 新款 MG4：首页原位单指水平及斜向拖动可旋转，模型外继续滚动。检查浅/深主题的前后侧、悬浮顶、黑色横板、前挡黑边、天幕、轮毂、车牌、玻璃、灯组和双色座舱。选择任意原厂色，检查悬浮顶切换和重启回读。验证车门、车窗、后备箱和充电口盖动作姿态及复位。
2. 展车涂装：依次选择红黑、黄黑、青白，检查全车、车门与后备箱开合，随后恢复原厂色。使用系统文件选择器导入本机或 iCloud PNG/JPEG，验证取消、无效文件、亮面/哑面、保留本机贴图和按账号及车辆回读。
3. 小组件：在同一桌面添加中号「兼容版」和「可选风格」，在 App 切换设计 01/02，给可选风格另设独立样式。分别核对时间线、快照、占位回执、桌面实际内容、操作入口和取消反馈。iOS 27 普通证书设备为本轮重点复测对象。
4. 充电：回归开始、自动更新间隔、缓存超时后继续读、较新的 1011 结束状态、返回车控和关闭状态岛。核对首页通用背景和原车模充电口盖。实车动作以明确授权及新车况闭环为准。
5. 保留既有登录、车况读回、蓝牙配对及钥匙、锁车与哨兵复验项。不要为了测试普通签名 Widget 卸载现有 App、清除或重领钥匙。
