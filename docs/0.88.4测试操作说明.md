# 0.88.4（105）测试操作

1. 按现有签名方式覆盖安装，确认账号、车辆、蓝牙钥匙和小组件能继续使用。
2. 在新款 MG4 首页切换浅深模式、车色和悬浮顶。拖动车模，看月光白、东来紫的亮度及星野灰的轮廓。
3. 车辆充电时核对首页和充电页的充电场景。查看光影和流光，然后检查结束后的车控页恢复。实际车控按用户授权操作。
4. 在「车控 → 能耗数据 → 自动行程记录」开启记录。停车后读取车况缓存，核对上报时间和末次结果。继续观察同编号累计、隔一段时间再读取、后台刷新以及重启后读回。
5. 若出现问题，分别记录安装包类型、iOS、机型、界面反馈及车辆状态时间。按钮、系统弹窗、小组件宿主和实车结论按实际场景记录。
