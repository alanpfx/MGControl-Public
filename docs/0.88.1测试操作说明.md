# 0.88.1（102）使用与验收

按安装方式选择普通带小组件、仅主 App 或 TrollStore 专用包，优先覆盖安装并保留已有钥匙。构建测试、包检查、真机安装和实车结果分别记录。

## 蓝牙阶段诊断与系统重连

在蓝牙钥匙的无感开关锁设置中，先暂停监测，再按需要开启“系统自动重连（实验）”。默认关闭，仅 iOS 17 及以上显示；下次连接生效。系统恢复连接后仍需重新认证，不会重放之前的车辆指令。请分别记录关闭和开启时的后台断线、返回范围、认证与动作回执，以及耗电差异。

“检查后台条件（不控车）”只检查实时活动和配件条件。iOS 26 实时活动对照要求先创建蓝牙管理器，再创建活动；如创建顺序不符，先启动监测，再关闭并重新开启实时活动。条件满足不保证系统常驻或自动解锁成功。

本版尚未启用配件授权迁移，不需要删除或重新领取数字钥匙。车控结果未知时先核对车辆，不连续重复下发。

## 充电电气数据更新

设置 → 关于 → 充电电气数据 · 更新与诊断。

1. 车辆稳定充电时先读取缓存，记录电池电压、电流、计算功率和数据时间。电池侧功率与充电桩功率可能不同。
2. 点击手动更新会在核对近期充电状态后提交一次更新，并有限查询较新的缓存。数值相同但数据时间推进也可能正常；成功受理但时间不变不能算已刷新。
3. 自动更新默认关闭，可选 1、2、5、10、30 分钟。只在 App 前台且确认充电时运行，后台不保证执行；恢复前台不会补发一串请求。失败或结果未确认时保留旧数据并暂停自动更新，手动验证后再开启。
4. 自动设置按当前远控账号和车辆区分；切换账号或车辆后核对设置。复制结果后应有就近反馈。该诊断数据尚未写入首页电气字段。
