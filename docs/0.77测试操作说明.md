# 0.77（72）测试操作说明

MGControl 0.77 (72) 设备与实车验收

已完成层（具体证据以 BUILD-STATUS.json 最终结果为准）：
- 本地版本/配置/编码检查；18项Python构建脚本测试。
- GLB范围/结构/10组动画检查；实际捆绑Babylon的本地WebGL 13项回归。
- 云端XCTest/编译与三类最终IPA核验在完成后另行记录。
未完成层：iOS设备安装/交互、系统权限、实际广播可见性及车辆动作。

1. 选择安装包
普通证书使用widget-ready，核对签名双端共同App Group；不需要组件使用app-only。
TrollStore使用widget-trollstore-appgroups，覆盖安装与首次安装分开记录。
不要为了测试新界面清除或重新领取现有蓝牙钥匙。

2. 设置反馈
进入蓝牙钥匙→无感开关锁设置，调整等待秒数后点击保存。
应立即看到结果弹窗和按钮上方的结果说明；返回再进入数值相同。
保存失败应明确原因，不能显示成功；车控执行中请等本次结果后再保存。
在自动刷新页保存不同间隔，确认弹窗、状态与重进后间隔一致。
对实际自动开关锁应在停车状态、保留实体钥匙、可目视实车时单独验证。

3. 主账号凭证入口
设置→登录/更新主账号凭证：第一次点应出现影响确认，取消不改变凭据。
点继续应直接弹出短信登录窗口；窗口取消、短信失败、登录失败均保留车辆和最近车况。
成功后设置显示掩码手机号，可读取车辆和车况；蓝牙账号/钥匙不重新配置。
确认设置中两个历史实验入口已移除。

4. 首页与隐私
已登录且有车辆时不再显示整块登录说明与读取车辆按钮；车辆重读移到设置。
手机号只显示前三位和后四位。首页不再出现模型参考/拖动/后备箱脚注。
实际失败仍应有可读反馈；滚动到各页最底部可把最后选项滑到悬浮导航上方。

5. iBeacon
已有手动参数用户：无需重领、无需重新配对；确认原UUID/Major/Minor和开启状态仍在。
真正首次配置设备时，扫描若收到同一iOS设备重复一致的新鲜iBeacon帧，认证并保存目标后
应保存参数，但辅助开关默认关闭。系统未提供广播时应显示手动填写说明，不阻止基础配对。
更换认证设备时不得沿用前一设备的辅助参数或自动开启。
在停车处与远处分别锁屏静置后走近，记录收到入区→连接→认证→解锁各阶段的耗时。
分别对比辅助开/关；权限设为始终允许。入区不是车辆认证，也不直接发送开关锁。
记录是否强退、系统版本、低电量/后台刷新状态；不承诺强退后唤醒或实时RSSI。

6. 模型
六色换色、明暗系统外观、前后车牌/车标与灯罩内部细节。
演示打开→关闭→恢复车况，外侧后灯留在车身；中部灯带/高位灯按尾门结构运动。
机盖开合不能带走前大灯。门窗动画互不串动，未知状态不能显示已关的确认结果。
模型只是展示，演示动画不发送真实车辆指令。

7. 旧功能定向回归
同一设备在线/离线BLE连接与一次明确锁车、解锁；在线锁车后的较新车况核验。
主/分享蓝牙账号与主账号远控凭证独立；证书/巨魔的小组件运行时读取版本和时间。
若测试自动哨兵，分别记录请求受理、最终结果与车况状态，不把单次成功外推全部设备。

补充：暂停监测应立即有结果；哨兵设置的允许询问通知，应显示已允许或未授权的具体结果。
