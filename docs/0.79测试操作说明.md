# 0.79 中号小组件测试

1. 保留已有车辆和钥匙覆盖安装，先读取车况。设置中依次选择经典、设计01、设计02，回桌面观察中号组件更新；系统调度可能延后。
2. 核对苹方文字、电量、续航、锁态、温度及数据时间与App快照一致；未知值不显示示例数值，过期数据需有提示。
3. 图片版显示原设计白色车辆，透明边缘无黑底；简洁版没有车辆图片。长车名和不同组件尺寸不遮挡。
4. 四个完整按钮区域都能点击：车锁、寻车、空调、后备箱。应进入App确认页，不应在打开时直接控车；取消不发送，车辆切换后重新确认。车窗旧链接仍可用。
5. 浅色、深色、iOS26全彩/透明/着色模式分别检查。透明模式的系统重着色不等于原全彩稿；静态高光不保证动态玻璃折射。
6. 切换车辆、重启App后风格保留。没有共享组授权时提示保存失败，保留原风格和车况。
7. 小号/大号、实时活动、登录、离线钥匙、远控与增强连接按原清单回归。
