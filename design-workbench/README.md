# MG UI 设计工作台 0.1（1）

独立于MGControl的原生SwiftUI仿真设计工具，最低iOS15.0。应用标识为 `com.alanpfx.MGControl.DesignWorkbench`，可与正式App并存，不需要登录或车辆授权，不包含车控接口、蓝牙、定位、钥匙或真实账号。

## 首版能力

- 点击“调整样式”修改方案，在“查看预览”查看原生布局；底部可切换首页与舒适控制。
- 全局页面边距、组件间距、卡片内边距、圆角、阴影、标题字号和车辆展示高度。
- 为13类控件分别修改SF Symbol名称、按钮文字、圆形直径、图标字号、文字字号和图文间距。
- 浅色/深色主题色和卡片颜色、内置车辆外观、四张首页卡片排序。
- 320/375/390/430pt画布、长文本、缺失数据和大字体压力测试；较宽画布可横向滚动。
- 点击图标只产生模拟反馈；后备箱为禁用占位。车锁、空调和座椅状态仅供预览。
- 有效参数自动保存在本机；右上菜单导出完整JSON设计文件，也可从“文件”导入；导入前校验格式版本、组件集合、参数范围及本机系统图标。

## 给设计师的操作步骤

1. 安装独立工作台IPA；巨魔或自有签名方式均需按系统条件选择。无需卸载正式MGControl。
2. 先调整整体布局与浅深色，再选择控件精调。尺寸单位是pt，不是截图像素。
3. “导出设计文件”保存 `MGControl-Design-v1.json`；建议用方案名另存不同版本。
4. 把JSON与对应iPhone型号、系统版本、字体大小、参考截图一起发送给开发者。
5. 可导回文件检查；恢复默认前先导出旧方案。

## 当前边界

首版为参数式编辑，不包含电脑端编辑器、自由拖拽、自定义图片图标上传、打包外部素材或导出截图功能。系统图标随iOS版本可能有差异，不支持的符号在导入/导出时会提示。

正式MGControl目前尚未读取此格式。开发者后续会把共享配置/渲染方式接入正式应用，并将固定控件映射到已有功能。在完成接入和同机截图对照之前，不宣称1:1自动还原。设计文件不允许定义网络地址、真实车控命令或可执行代码。

工作台中的车辆状态、地址、温度等均为示例，空调操作不会发送到真实车辆。当前控车协议的温控范围25–29℃仅作为示例控件约束保留。
